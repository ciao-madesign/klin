# Klin theme

Klin's look for the browser itself (tabs, toolbar, address bar, menus): dark, one lime accent, from `docs/STYLE.md`. A theme extension, no code. Not a patch: the name "Firefox" in the title bar, the program icon and "About" stay until the rebranded build (stage 2, own ADR).
**Limits:** dark only (no light or system switch yet); colours only, no shapes; Firefox's own pages (settings, add-ons) keep their layout.
Test: `tests/acceptance/newtab` (toolbar colour).
