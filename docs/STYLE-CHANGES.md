# Style changes on the existing screens

Status 13 Nov 2026: **applied** by the style session at the owner's request. All acceptance tests that need Firefox 160 were run and pass (welcome, private window, lookalike, collection log, photo privacy, connections, self-test), plus the new static test `tests/acceptance/style/run.py`. Source of truth for the look: `STYLE.md`.

## What was done
- **Shared foundation.** `extensions/_shared/` holds the style sheet (`klin.css`: tokens, fonts, cut corner, highlighter, badges), the strings loader (`i18n.js`) and the four bundled fonts with their licences. `build/sync-shared.py` copies them into each extension (`<ext>/shared/`); `--check` fails if a copy drifts. Edit only `_shared/`, then run the script.
- **Strings.** Every extension has `_locales/en` and `_locales/it`. Pages keep their English text in the HTML (so they still read if nothing loads) and `data-i18n` keys replace it; markup in messages: `**bold**`, `==highlighter==`, `` `code` ``. Manifest names, descriptions and button titles use `__MSG_*__`. The browser's language picks Italian or English.
- **Welcome page and Greenweb page:** logo, tagline, values line with ecology, one highlighted phrase ("Klin non ti rende anonimo"), serif for long reading, "Draft wording" line removed.
- **Photo dialog** (`photo-privacy/content.js`): new wording and buttons, cut corner, one highlighted sentence. It uses system fonts, because a content script cannot load the extension's fonts into a site's page without exposing them to the site.
- **Lookalike warning, private window, collection log popup, self-test, connections:** new tokens, fonts, cut corners, badges with a word and a shape (never colour alone), new wording in both languages. The difference between two names is marked in the warning colour, not with the highlighter.
- **Icons and badge:** logo in `branding/` (SVG masters); toolbar icons redrawn with square caps and the theme's own colour (`context-fill`); the collection-log badge uses lime (calm) and amber (worry) with black text.
- **Tests:** `tests/acceptance/style/run.py` checks that the shared copies are in sync, both languages have the same messages, placeholders and markup, the English text in each page equals its English message, no page loads anything from the internet, no colour from the old drafts is left, and every colour pair reaches 4.5:1.
