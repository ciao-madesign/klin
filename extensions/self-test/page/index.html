What a site can see

This page runs the same checks a tracking script would run, on your machine only. Nothing is sent, nothing is stored.

Running the checks…

Protected: the site gets nothing useful, or a value that is blurred or shared with many other users. Exposed: the site gets a value that helps to recognise you and that could be hidden. Visible: normal for any browser, but each value adds to your fingerprint.

The test shows what is technically readable, not how rare your combination is: that would need comparing you with other users, which Klin does not do.
